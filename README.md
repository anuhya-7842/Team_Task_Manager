# Team Task Manager

## Project Overview
Team Task Manager is a full-stack Flask web application where users can create projects, assign tasks, and track task progress with role-based access.

## Features
- User Signup/Login Authentication
- Project Management
- Task Creation
- Task Assignment
- Status Tracking
- Dashboard
- Logout Functionality

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- SQLAlchemy

### Activate Virtual Environment

### Install Dependencies

### Run Application
python app.py
